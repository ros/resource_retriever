# resource_retriever

This repository contains the [resource_retriever](resource_retriever) ROS 2 package, which loads the content of `package://`, `file://`, `http://` and `https://` URLs into memory, in C++ and in Python.

* [Package overview](resource_retriever/README.md)
* [Documentation and tutorials](resource_retriever/doc/index.rst), published at [docs.ros.org](https://docs.ros.org/en/rolling/p/resource_retriever/)
